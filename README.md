# Incident Handler's Journal – Ransomware Case Study

##  Description
This repository contains an Incident Handler's Journal documenting a cybersecurity incident involving a ransomware attack delivered via phishing emails.  

The project was completed as part of the **Google Cybersecurity Professional Certificate** and demonstrates incident documentation, analysis, and reporting skills.

##  Objectives
- Practice incident documentation using the Incident Handler’s Journal
- Apply the 5 W’s framework to a real-world ransomware scenario
- Build a professional cybersecurity portfolio artifact

##  Skills Demonstrated
- Incident response documentation
- Phishing and ransomware analysis
- Cybersecurity reporting
- Security awareness and risk analysis
